# Trading Journal

An advanced trading journal for recording, reviewing, and analyzing trades with performance metrics, statistics, and visual insights.

## Preview

![Dashboard](src/assets/images/dashboard.png)

![Trade List](src/assets/images/list.png)

![Place Trade](src/assets/images/placetrade.png)

## Features

- Trading dashboard
- Trade management
- Trade history
- Performance statistics
- Trading analytics
- PostgreSQL database
- REST API
- Angular frontend
- Spring Boot backend

## Tech Stack

### Frontend

- Angular 21
- TypeScript 5.9
- SCSS
- Chart.js
- SweetAlert2
- RxJS

### Backend

- Java 21
- Spring Boot 4.1.1
- Spring Data JPA
- Hibernate
- PostgreSQL
- Lombok
- Maven

## Requirements

Make sure you have installed:

- Java 21
- Node.js
- npm 10+
- Angular CLI 21
- PostgreSQL 14+
- Maven
